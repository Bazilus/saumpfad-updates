# Saumpfad – Updates

Dieses Repository verteilt Updates für das Spiel **Saumpfad**. Das Spiel liest hier im Hintergrund
`update.json` und lädt das darin genannte Spielpaket (`.pck`). Jedes Paket ist signiert; das Spiel
nimmt nur Pakete mit gültiger Signatur und passender Prüfsumme an.

Gepflegt wird es mit `veroeffentlichen.py` aus dem Spiel-Repository – bitte nicht von Hand ändern.
